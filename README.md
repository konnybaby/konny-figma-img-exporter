# Konny Image Exporter

선택한 프레임 아래에서 `KO???_img_...` 형식의 레이어만 골라, 2x PNG로 한 번에 내보내는 Figma 플러그인입니다.

## 설치

빌드 과정이 없습니다. 이 폴더를 그대로 등록하면 됩니다.

1. Figma 데스크톱 앱 실행
2. 메뉴 → **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json` 선택
4. 이후 **Plugins → Development → Konny Image Exporter** 로 실행

## 사용법

1. 캔버스에서 프레임을 선택합니다 (예: `Frame 2609726`).
   - 아무것도 선택하지 않으면 **현재 페이지 전체**가 대상이 됩니다.
   - 프레임 여러 개를 동시에 선택해도 됩니다.
2. 플러그인을 실행하면 조건에 맞는 레이어 목록이 바로 표시됩니다.
3. 기본값(2x / PNG / ZIP) 그대로 **이미지 내보내기** 를 누릅니다.

캔버스 선택을 바꾸면 목록이 자동으로 다시 스캔되므로 따로 스캔 버튼을 누를 필요가 없습니다.
목록의 항목을 클릭하면 해당 레이어가 캔버스에서 선택되고 화면이 이동합니다.

## 옵션

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 레이어 이름 패턴 | `^KO[A-Za-z0-9]{3}_img_` | 정규식. 이름이 이 패턴으로 시작하는 레이어만 대상 |
| 배율 | 2x | 1x / 2x / 3x / 4x, `1000w` = 가로 1000px 고정 (PNG·JPG에만 적용) |
| 포맷 | PNG | PNG / JPG / SVG / PDF |
| 저장 방식 | ZIP 압축 파일 | `Figma 내보내기` / `개별 파일` 로 변경 가능 — 아래 참고 |
| 숨김 레이어 제외 | 켬 | 눈 아이콘이 꺼진 레이어를 건너뜀 |
| 이름 순 정렬 | 켬 | `_01, _02, _10` 순서가 사람 눈 순서대로 정렬됨 |

## 동작 규칙

- **중첩 방지** — 패턴에 맞는 레이어를 찾으면 그 안쪽으로는 더 내려가지 않습니다.
  `KO214_img_lookbook_01` 안에 또 `KO214_img_...` 가 있어도 바깥쪽 것 하나만 내보냅니다.
- **파일명** — 레이어 이름을 그대로 쓰되 `\ / : * ? " < > |` 는 `_` 로 바꿉니다.
  이름이 겹치면 `_2`, `_3` 이 붙습니다.
- **내보내기 실패** — 크기가 0인 레이어처럼 내보낼 수 없는 항목은 건너뛰고,
  나머지를 모두 내보낸 뒤 하단에 실패 목록을 보여줍니다.
- **1000w** — 원본 크기와 무관하게 가로 1000px에 맞춰 내보냅니다(세로는 비율 유지).
- 레이어에 이미 설정된 Export 설정은 무시하고, 플러그인의 배율·포맷을 사용합니다.

## 저장 방식 세 가지

플러그인은 파일을 디스크에 직접 쓸 수 없습니다. File System Access API
(`showDirectoryPicker` 등)는 플러그인 UI iframe에서 아예 정의되지 않고, 다운로드는
파일마다 저장 창이 뜨는 데다 한 번에 열 수 있는 개수도 10개 안팎으로 제한됩니다.
그래서 목적에 따라 세 가지를 고를 수 있게 했습니다.

| 방식 | 저장 창 | 결과물 |
| --- | --- | --- |
| **ZIP 압축 파일** (기본) | 1번 | ZIP 하나. 풀어서 쓰면 됨 |
| **Figma 내보내기** | 1번 (폴더) | 개별 PNG 파일. 아래 설명 참고 |
| **개별 파일** | 파일 수만큼 | 개별 PNG 파일. 10개 안팎까지만 |

### Figma 내보내기

개별 파일을 폴더 하나에 한 번에 저장하고 싶을 때 씁니다. 플러그인이 대상 레이어에
Export 설정(배율·포맷)을 넣고 전부 선택해 주면, 그다음은 **Figma 자체 Export 기능**이
폴더를 한 번만 묻고 개별 파일로 전부 저장합니다. 개수 제한도 없습니다.

1. 저장 방식에서 `Figma 내보내기` 선택
2. **Export 설정 넣고 선택하기** 를 누름 — 대상 레이어가 모두 선택됨
3. 캔버스를 한 번 클릭해 포커스를 옮기고 **Shift+Ctrl+E** (Mac은 **⇧⌘E**)
   — 또는 오른쪽 Design 패널 맨 아래 **Export N layers** 버튼

3번을 플러그인이 대신 눌러줄 수는 없습니다. Figma 플러그인 API에는 Export 같은
에디터 메뉴 동작을 실행하는 수단이 없고(`figma` 전역에 있는 UI 관련 메서드는
`notify` / `showUI` / `closePlugin` / `triggerUndo` 정도가 전부입니다), 플러그인 UI는
교차 출처 iframe이라 Figma 문서에 키 이벤트를 흘려보낼 수도 없습니다.

> 이 방식은 레이어의 Export 설정을 실제로 바꿉니다(문서가 수정됨).
> 되돌리려면 Figma에서 실행 취소(Ctrl/Cmd+Z) 하면 됩니다.

## 구성

```
manifest.json   플러그인 정의
code.js         메인 스레드 — 레이어 탐색 + exportAsync
ui.html         패널 UI + ZIP 생성 + 다운로드
```

ZIP은 외부 라이브러리 없이 `ui.html` 안에서 직접 만듭니다(무압축 store 방식 —
PNG/JPG는 이미 압축돼 있어 재압축 이득이 거의 없음). 이미지 처리는 전부 로컬에서 이뤄집니다.

## 디자인

UI는 **Konny PDP Text Exporter** 의 스타일시트를 그대로 가져와 맞췄습니다.

- 폰트 `Pretendard, Apple SD Gothic Neo` / 본문 13px / 라인하이트 1.5
- 배경 `#fbf6ed`, 텍스트 `#1a1a1a`, 보더 `#c2c2c2`, 보조 텍스트 `#888`
- 포인트 컬러 `#FF5A14` — 칩 배경 `#fff0e5`, 칩 보더 `#fadac3`
- 헤더 `16px 20px 12px` + 하단 보더, 로고 36px 원형, 타이틀 15px/700/-0.3px, 서브타이틀 11px `#888`
- 섹션 라벨 10px/700/자간 0.8px 대문자, 입력·버튼 radius 8px, 칩 radius 20px
- 하단 검정 버튼 1개, 창 크기 440 x 680

헤더 로고는 PDP Text Exporter와 같은 이미지(`konny.co.kr` 파비콘)를 씁니다. 이 때문에
`manifest.json` 의 `networkAccess` 에 `https://konny.co.kr` 만 허용해 두었습니다.
