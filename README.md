# Konny Figma Image Exporter

Figma 레이어를 2x PNG로 한 번에 내보내는 플러그인입니다. 캔버스에서 고른 레이어를
바로 내보내거나, 이름 규칙(`KO???_img_...`)으로 자동으로 골라낼 수 있습니다.

## 설치

빌드 과정이 없습니다. 이 폴더를 그대로 등록하면 됩니다.

1. Figma 데스크톱 앱 실행
2. 메뉴 → **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json` 선택
4. 이후 **Plugins → Development → Konny Figma Image Exporter** 로 실행

## 대상 지정 두 가지

| 방식 | 무엇을 내보내나 | 언제 쓰나 |
| --- | --- | --- |
| **선택한 레이어** (기본) | 캔버스에서 고른 레이어를 **이름과 무관하게** | 그때그때 필요한 레이어를 뽑을 때 |
| **이름 패턴으로 찾기** | 고른 프레임 **아래에서** 이름이 패턴에 맞는 레이어 | 이름 규칙이 잡혀 있는 정기 작업 |

`선택한 레이어` 일 때는 패턴 입력칸이 숨겨집니다.

## 사용법

**선택한 레이어** (기본)

1. 캔버스에서 내보낼 레이어를 고릅니다 (Shift 클릭으로 여러 개 가능)
2. 기본값(2x / PNG / ZIP) 그대로 **이미지 내보내기** 를 누릅니다

**이름 패턴으로 찾기**

1. 대상 지정에서 `이름 패턴으로 찾기` 선택
2. 캔버스에서 프레임을 선택합니다 (예: `Frame 2609726`).
   - 아무것도 선택하지 않으면 **현재 페이지 전체**가 대상이 됩니다.
   - 프레임 여러 개를 동시에 선택해도 됩니다.
3. 조건에 맞는 레이어 목록이 바로 표시됩니다. **이미지 내보내기** 를 누릅니다

캔버스 선택을 바꾸면 목록이 자동으로 다시 스캔되므로 따로 스캔 버튼을 누를 필요가 없습니다.
목록의 항목을 클릭하면 해당 레이어가 캔버스에서 선택되고 화면이 이동합니다.

## 축소 / 확대

내보낼 프레임을 찾는 동안 창이 화면을 가리지 않도록, 헤더 오른쪽 버튼으로 창을
접었다 펼 수 있습니다.

| 상태 | 크기 | 보이는 것 |
| --- | --- | --- |
| 확대 | 360 × 600 | 전체 설정 |
| 축소 | 360 × 156 | 요약 한 줄(`7개 · 2x · PNG · ZIP`) + 내보내기 버튼 |

축소 상태에서도 내보내기는 그대로 동작합니다. 마지막 상태는 저장돼 다음 실행 때
그대로 열립니다.

## 옵션

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 대상 지정 | 선택한 레이어 | `이름 패턴으로 찾기` 로 변경 가능 |
| 레이어 이름 패턴 | `^KO[A-Za-z0-9]{3}_img_` | 정규식. `이름 패턴으로 찾기` 일 때만 적용 |
| 배율 | 2x | 1x / 2x / 3x / 4x, `1000w` = 가로 1000px 고정 (PNG·JPG·WebP에만 적용) |
| 포맷 | PNG | PNG / JPG / WebP / SVG / PDF |
| 저장 방식 | ZIP 압축 파일 | `개별 파일(Figma 내보내기)` 로 변경 가능 — 아래 참고 |
| 숨김 레이어 제외 | 켬 | 눈 아이콘이 꺼진 레이어를 건너뜀 |
| 이름 순 정렬 | 켬 | `_01, _02, _10` 순서가 사람 눈 순서대로 정렬됨 |
| Clip content 켜기 | 켬 | 내보내기 전에 대상 레이어의 `Clip content` 를 켬 — 아래 참고 |

## 동작 규칙

- **중첩 방지** (이름 패턴 모드) — 패턴에 맞는 레이어를 찾으면 그 안쪽으로는 더 내려가지
  않습니다. `KO214_img_lookbook_01` 안에 또 `KO214_img_...` 가 있어도 바깥쪽 것 하나만
  내보냅니다. `선택한 레이어` 모드는 고른 것만 쓰므로 하위 탐색을 하지 않습니다.
- **파일명** — 레이어 이름을 그대로 쓰되 `\ / : * ? " < > |` 는 `_` 로 바꿉니다.
  이름이 겹치면 `_2`, `_3` 이 붙습니다.
- **내보내기 실패** — 크기가 0인 레이어처럼 내보낼 수 없는 항목은 건너뛰고,
  나머지를 모두 내보낸 뒤 하단에 실패 목록을 보여줍니다.
- **1000w** — 원본 크기와 무관하게 가로 1000px에 맞춰 내보냅니다(세로는 비율 유지).
- **Clip content** — 내보내기 직전에 대상 레이어의 `Clip content`(API 의 `clipsContent`)
  를 켭니다. 꺼져 있으면 프레임 밖으로 삐져나온 자식까지 함께 내보내져 결과 크기가
  프레임과 달라집니다. 이미 켜져 있는 레이어는 건드리지 않고, 프레임 계열이 아닌
  레이어(그룹 등)에는 이 속성이 없어 건너뜁니다.

  > 이 옵션은 **문서를 수정합니다.** 몇 개를 새로 켰는지 상태 줄에 표시되며,
  > Figma에서 실행 취소(Ctrl/Cmd+Z)로 되돌릴 수 있습니다. 원치 않으면 칩을 끄세요.
- 레이어에 이미 설정된 Export 설정은 무시하고, 플러그인의 배율·포맷을 사용합니다.

## 저장 방식 두 가지

플러그인은 파일을 디스크에 직접 쓸 수 없습니다. File System Access API
(`showDirectoryPicker` 등)는 플러그인 UI iframe에서 아예 정의되지 않고, 다운로드는
파일마다 저장 창이 뜨는 데다 한 번에 열 수 있는 개수도 10개 안팎으로 제한됩니다.
그래서 저장 창이 한 번만 뜨는 두 가지만 남겼습니다.

| 방식 | 저장 창 | 결과물 |
| --- | --- | --- |
| **ZIP 압축 파일** (기본) | 1번 | ZIP 하나. 풀어서 쓰면 됨 |
| **개별 파일(Figma 내보내기)** | 1번 | 데스크톱 앱은 폴더에 개별 파일, 브라우저는 ZIP |

### 개별 파일(Figma 내보내기)

개별 파일을 한 번에 저장하고 싶을 때 씁니다. 플러그인이 대상 레이어에 Export
설정(배율·포맷)을 넣고 전부 선택해 주면, 그다음은 **Figma 자체 Export 기능**이
저장을 처리합니다. 플러그인 다운로드와 달리 개수 제한이 없습니다.

1. 저장 방식에서 `개별 파일(Figma 내보내기)` 선택
2. **Export 설정 적용** 을 누름
   — 대상 레이어에 배율·포맷이 심기고, **캔버스 선택이 프레임에서 대상 레이어들로 바뀝니다**
3. 오른쪽 Design 패널 맨 아래 **Export N layers** 버튼을 누름

2번에서 선택을 바꾸는 이유는, Figma의 Export 가 **그 시점에 선택된 것**을 내보내기
때문입니다. 프레임이 선택된 채로 Export 하면 대상 레이어 N장이 아니라 프레임 1장이
통째로 나갑니다.

> **캔버스를 클릭하지 마세요.** 빈 곳을 클릭하면 선택이 전부 풀리고, 레이어를
> 클릭하면 그 하나만 선택됩니다. 어느 쪽이든 2번에서 잡아둔 선택이 사라집니다.
> 단축키 **Shift+Ctrl+E**(Mac **⇧⌘E**)도 쓸 수 있지만, 플러그인 창에 키보드
> 포커스가 있으면 Figma로 전달되지 않을 수 있습니다. 패널 버튼이 가장 확실합니다.

**저장 결과는 실행 환경에 따라 다릅니다.**

- **데스크톱 앱** — 저장 위치를 한 번 묻고 개별 파일로 저장합니다
- **브라우저** — 여러 개를 한 번에 내보내면 **ZIP 하나로** 받아집니다
  (이 경우 플러그인의 `ZIP 압축 파일` 방식과 결과가 같습니다)

3번을 플러그인이 대신 눌러줄 수는 없습니다. Figma 플러그인 API에는 Export 같은
에디터 메뉴 동작을 실행하는 수단이 없고(`figma` 전역에 있는 UI 관련 메서드는
`notify` / `showUI` / `closePlugin` / `triggerUndo` 정도가 전부입니다), 플러그인 UI는
교차 출처 iframe이라 Figma 문서에 키 이벤트를 흘려보낼 수도 없습니다.

> 이 방식은 레이어의 Export 설정을 실제로 바꿉니다(문서가 수정됨).
> 되돌리려면 Figma에서 실행 취소(Ctrl/Cmd+Z) 하면 됩니다.

## WebP

Figma는 WebP 내보내기를 지원하지 않습니다(`ExportSettings.format` 은 PNG / JPG /
SVG / PDF 뿐). 그래서 플러그인이 **PNG로 받아 캔버스에서 WebP로 다시 인코딩**합니다
— 커뮤니티 WebP 플러그인들이 쓰는 방식과 같습니다. 품질은 `0.90`, 투명도는 유지됩니다.

변환이 플러그인 안에서 일어나므로 **`개별 파일(Figma 내보내기)` 방식과는 함께 쓸 수
없습니다.** 그 방식은 Figma 자체 Export 를 쓰기 때문입니다. WebP 를 고르면 저장 방식이
`ZIP 압축 파일` 로 자동 전환되고, `개별 파일(Figma 내보내기)` 칩이 비활성화됩니다.

## 구성

```
manifest.json   플러그인 정의
code.js         메인 스레드 — 레이어 탐색 + exportAsync
ui.html         패널 UI + WebP 변환 + ZIP 생성 + 다운로드
```

ZIP은 외부 라이브러리 없이 `ui.html` 안에서 직접 만듭니다(무압축 store 방식 —
PNG/JPG는 이미 압축돼 있어 재압축 이득이 거의 없음). 이미지 처리는 전부 로컬에서 이뤄집니다.

## 디자인

UI는 **Konny PDP Text Exporter** 의 스타일시트를 그대로 가져와 맞췄습니다.

- 폰트 `Pretendard, Apple SD Gothic Neo` / 본문 13px / 라인하이트 1.5
- 배경 `#fbf6ed`, 텍스트 `#1a1a1a`, 보더 `#c2c2c2`, 보조 텍스트 `#888`
- 포인트 컬러 `#FF5A14` — 칩 배경 `#fff0e5`, 칩 보더 `#fadac3`
- 헤더 `16px 20px 12px` + 하단 보더, 로고 36px 원형, 타이틀 15px/700/-0.3px, 서브타이틀 11px `#888`
- 섹션 라벨 10px/700/자간 0.8px 대문자, 입력·버튼 radius 8px, 칩 radius 20px
- 하단 검정 버튼 1개, 창 크기 360 x 600 (축소 시 360 x 156)
- 설정 영역만 스크롤되고 `내보낼 레이어` 목록과 버튼은 항상 보이도록 고정

헤더 로고는 PDP Text Exporter와 같은 이미지(`konny.co.kr` 파비콘)를 씁니다.
`manifest.json` 의 `networkAccess` 에는 이 로고 도메인 한 곳만 허용해 두었습니다.
